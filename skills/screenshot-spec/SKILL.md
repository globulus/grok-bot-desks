# Screenshot spec

## Sequence

1. Platforms and required sizes (current iOS/Android listing rules — look up live docs if unsure; do not freeze old pixel sizes as eternal truth).
2. Ordered narrative: 5–8 frames, caption per frame, no tiny unreadable UI.
3. Localization: which screens need new copy vs reusable chrome.
4. Checklist: status bar, fake accounts only, no production PII.

## Output

Ordered shot list + caption + device + "blocker if missing".
